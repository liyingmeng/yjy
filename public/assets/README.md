# Media replacement slots

- `portrait.jpg`: personal portrait used in the profile section.
- `li-yingmeng-resume.pdf`: downloadable resume.
- `hero-loop.mp4`: optional muted looping hero video. After adding it, set `media.heroVideo` in `src/content.js` to `/assets/hero-loop.mp4`.
- Project images: add files here and set each project's `image` field in `src/content.js`, for example `/assets/project-sam3.jpg`.

The current version intentionally uses structured placeholders until final media is supplied.
